[h2]For Mod Creators[/h2]

Want to build your own PearDock app?

PearDock Core includes an add-on API so other creators can publish completely separate apps without modifying the core.

Custom apps provide their own:
[list]
[*]App name
[*]App icon
[*]Fixed window size
[*]UI Toolkit content
[*]Game logic
[/list]

PearDock Core handles the dock, Home, app window, Pin/Unpin, X close button, dragging and saved window positions.

[b]PearDock Developer Kit:[/b]
[url=YOUR_GITHUB_LINK]GitHub / Developer Kit[/url]

The Developer Kit includes:
[list]
[*]API documentation
[*]Ready-to-use add-on template
[*]Setup guide
[*]Troubleshooting guide
[/list]

PearDock Core is required for PearDock add-on apps.
